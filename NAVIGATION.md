## How to use this repository

- Use the roadmap to choose a current milestone.
- Use the checklist as a prompt, not as a substitute for reasoning.
- Copy the lab template for each machine or focused exercise.
- Convert validated observations into report-ready findings.
- Add new notes under the nearest topic and link them here.

## Status labels

- `planned` — queued.
- `in progress` — currently being practiced.
- `validated` — reproduced in an authorized lab.
- `needs review` — version-specific or incomplete evidence.
