# OSCP Preparation Roadmap

This roadmap is practical and adjustable. Set the dates yourself; measure progress by repeatable skills and written evidence, not by a claim of certification.

## Phase 0 — Baseline and setup

- [ ] Confirm authorization, network boundaries and reset process.
- [ ] Prepare an assessment VM, snapshots and a notes repository.
- [ ] Refresh TCP/IP, Linux, Windows, shell, Python and Git fundamentals.
- [ ] Create a consistent command log and evidence naming convention.

## Phase 1 — Reconnaissance and enumeration

- [ ] Perform full TCP discovery and targeted version detection.
- [ ] Add UDP checks when justified by scope and time.
- [ ] Enumerate DNS, SMB, FTP, SSH, SMTP, SNMP, HTTP and databases.
- [ ] Identify virtual hosts, files, shares, users and naming patterns.
- [ ] Explain what each result changes in the next decision.

## Phase 2 — Web and service footholds

- [ ] Map applications manually before relying on automation.
- [ ] Test authentication, authorization, input, file handling and misconfiguration.
- [ ] Validate suspected vulnerabilities with minimal-impact proof.
- [ ] Track failed hypotheses so they are not repeated.

## Phase 3 — Privilege escalation

- [ ] Review users, groups, processes, services, scheduled tasks and permissions.
- [ ] Check credential and configuration exposure within authorized scope.
- [ ] Document prerequisites, reliability, cleanup and defensive indicators.

## Phase 4 — Active Directory fundamentals

- [ ] Understand domains, users, groups, computers, shares, policies and trusts.
- [ ] Enumerate only what the rules of engagement permit.
- [ ] Map access paths from evidence rather than guessing.
- [ ] Record the defensive control that would break each path.

## Phase 5 — Practice under constraints

- [ ] Complete timed, authorized exercises with a written plan.
- [ ] Use timeboxes for enumeration, foothold, escalation and documentation.
- [ ] Revisit missed paths from clean snapshots.
- [ ] Produce a complete report with reproduction and remediation.

## Weekly cadence

One fundamentals session, two focused lab sessions, one timed exercise, one report-writing session, and one retrospective.

## Readiness signals

Useful signals are being able to explain decisions, reproduce lab results, recover from dead ends and write a clear report. These are not a certification claim or a guarantee of exam readiness.
